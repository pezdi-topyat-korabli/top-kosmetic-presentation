# TOP Cosmetics — дизайн-концепции

Презентация 16 направлений дизайна для обсуждения с заказчиком: девять вариантов Семёна и семь вариантов Артёма. Откройте сайт GitHub Pages, чтобы посмотреть превью на компьютере и телефоне, сравнить два направления и перейти к интерактивным прототипам.

Это демонстрационные материалы, не рабочий магазин. Цены и наличие не подтверждены; оформление заказа и интеграции в прототипах не работают.

[Фото товаров: до/после](https://pezdi-topyat-korabli.github.io/top-kosmetic-presentation/media-stage/) теперь включает отдельное сравнение 22 белых и светло-серых карточек. [Electric](https://pezdi-topyat-korabli.github.io/top-kosmetic-presentation/prototypes/semyon/#/electric/catalog) показывает светло-серую подложку `#F2F2F2`. Фотографии остаются демонстрационными кандидатами; рабочий Bitrix не изменён.
