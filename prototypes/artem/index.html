Как выбирать

Что общее у всех

  • Полные названия без обрезки, объём виден сразу.
  • Фильтры видны, у каждого значения есть число товаров.
  • Одна заметная главная кнопка, контраст текста не ниже 4.5:1.
  • Работа с клавиатуры, видимый фокус, без прокрутки страницы вбок.

Что можно сочетать

  • Основу берём из одного варианта: сетку, шапку, типографику.
  • Отдельные блоки берём из других. Например, дерево разделов из A6, прайс для специалистов из A2, панель шоурума из A7.
  • Сочетание лучше выбрать до оценки работ.

Что нужно от магазина

  • Подтвердить наличие, акции и условия доставки.
  • Логотип и фото шоурума.
  • Решить, где править названия: в 1С или на витрине.
  • Полный список вопросов — в ARTEM_DESIGN_BITRIX_TRANSFER.md.
